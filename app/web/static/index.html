Danh sách học sinh

File Excel gồm các cột Lớp · Họ tên · Ngày sinh · Bán trú (Có/Không) · Tên gọi khác · Ăn ghép. File danh sách học sinh toàn trường (em tô chữ đỏ là ăn bán trú) cũng nhập được.

• Mỗi lần ghi, app tự sao lưu file cũ vào thư mục SaoLuu cạnh file (giữ 30 bản gần nhất).
• Nếu sổ đang mở trong Excel, hãy đóng Excel rồi bấm Lưu lại.
